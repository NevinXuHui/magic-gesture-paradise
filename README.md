# 灵动手势乐园

本仓库收录本机实时手势识别与剪刀石头布互动游戏的前端实现。项目使用 Vue 3、Element Plus 和 MediaPipe Tasks Vision，在浏览器本地读取摄像头并完成推理，摄像头画面不会上传。

## 项目目录

- `dog-h5-gesture`：实时手势识别 H5，包含多手势识别、主手跟踪与调试工具。
- `dog-pc-gestrue`：桌面网页版本的手势识别实验项目。
- `rps-kids-h5`：面向 800 × 480 屏幕的儿童剪刀石头布小游戏，支持摇拳触发、停稳识别、输赢动画与轨迹日志。

各项目的运行、构建及部署说明见对应目录内的 `README.md`。

## 环境

- Node.js 20+
- Chrome / Chromium
- 摄像头

模型与浏览器端 WASM 推理资源随源码提供，可在无外网环境运行。RK3588 + Ubuntu 24.04 的浏览器部署仍需结合摄像头驱动和目标设备性能实测。
