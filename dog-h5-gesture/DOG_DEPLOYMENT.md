# 机器狗额头相机版

部署目录：`/home/unitree/dog-h5-gesture`

访问：`http://192.168.123.99:8091`，点击“开始识别”。摄像头来自机器狗额头，MediaPipe 推理在访问网页的电脑浏览器执行。

启动：`cd /home/unitree/dog-h5-gesture && bash start-dog.sh`

没有添加开机任务。后端只订阅原厂 `video_gst` 已发布的 `/tmp/foo_jpeg` 共享内存流（JPEG，1920×1080），缩放到 640×360 后传给网页。不会自动停止原厂服务，也不会打开 `/dev/video*`。共享流不存在时 `/api/status` 会提示相机尚未供帧，需要原厂系统先开启该流。

网页点击“停止识别”只停止当前浏览器推理。局域网服务用于测试，不应暴露到公网。

验证：25 项算法测试通过；Chrome 实际加载 WASM 模型并处理狗端真实画面，测得一次单帧推理 63ms。测试画面无手，尚未验证真人剪刀、石头、布准确率。
